# 时间日历：固定15分钟追踪表

2026-10-21

## 使用

从「今天」或「智慧管家」打开时间日历。月历保留已确认的圆角卡片、淡蓝日期选择、分类色点和每日/每周切换。点击日期，直接进入独立的每日追踪页。

正常24小时日：Planned 与 Actual 各有96个独立按钮，每小时4格、每格15分钟，始终共用同一条时间轴。没有30分钟切换，也没有覆盖单格的整段活动按钮。

先选分类颜色，可选填写活动名称，再点击单格或用鼠标拖选。手机默认允许滑动和单格点击；主动开启「触摸拖涂」后才拦截滚动用于连续画，结束后可关闭。也可展开精确时段表单填写起止边界。选09:00开始、12:00结束会填12格。活动名称可应用到刚才选区，橡皮擦只清除选区，撤销保留误操作前的记录。

原计划对照、时间定位、日历时区收在折叠设置中。可以保留独立原计划快照，并只读核对；后续涂色不改变原计划。每次修改保留差量历史，不保存整份账号历史副本。

日统计、月历色点、周统计与周网格使用同一个 timeCalendar 数据源。Actual 每个完整填色格累计15分钟；未知单独计时，未记录时间和未来时间另列。周网格为7天×96个钟面位置，可点开当天；周总结、每日复盘可留空或以后补写。

## 旧记录和时区

- 数据仍沿用现有统一加密快照 schema 3、timeCalendar schemaVersion 1，以及现有账号版本检查。不新建数据库表，不修改 SQL/RLS、登录配置或加密算法。
- 连续格可共用一段存储记录；编辑中间一格会精确拆开左右剩余部分，而不是改整段。每一格始终独立可访问。
- 旧版不在15分钟边界上的记录不自动对齐、删除或取整。相应格显示「原记录非整格」，保留原始时长；主动涂改时仅替换该格内的旧内容，格外部分不变。
- 跨午夜记录按同一个绝对时刻保存；编辑某日末格会保留另一日的剩余部分。
- 当前日历固定沿用已有时区。普通24小时日为96格；若时区遇到夏令时，实际23/25小时日分别显示92/100个完整15分钟格，标明UTC偏移，不能伪造或丢弃一个小时。周网格按钟面显示，重复小时的精确内容以完整日表为准，周统计仍按实际分钟计算。
- 尚未结束的Actual格不能填色；未来日期可以规划，不会自动生成实际活动。

## 保存、隐私与恢复

涂色顺序排队写入，每次执行时检查当前账号与聚合修订，沿用已有AES-GCM本机密文缓存和自动云同步。页面只在本机加密成功后显示已保存；上传结果见账号同步状态。容量或写入错误显示重试/应急加密备份入口。账号锁定后清空新增网格、分类、日/周复盘DOM，明文不另存localStorage。

每日复盘仍是 reviews；每周总结首次保存时增量增加可选 weekReviews，字段与每日复盘一致，按周一与日历时区识别。新周总结历史类型为 weekReviews，旧版核心会拒绝不兼容历史，防止旧设备静默丢弃新字段。新旧设备请刷新到同一新版后继续编辑。

全部账号加密备份包含时间格、分类、原计划、每日复盘、每周总结、历史及原有其他模块。恢复预览明确显示每日与每周复盘数量；恢复仍需现有完整备份确认。多设备离线冲突仍使用整份密文CAS并保留双方副本，不冒充逐格自动合并。

## 回退

先下载当前完整账号加密备份。如仅需恢复旧界面，只替换 time-calendar.js 与 time-calendar.css 为界面回退目录里的旧版，保留新的 time-calendar-core.js、sync.js、index.html 与缓存设置。这样新周总结依旧保存在快照内，不会被旧界面写入路径删除。不要整提交回退到旧核心：旧核心不能读取含新周总结历史的快照。不要为回退界面而恢复旧资料备份，否则会失去备份之后的修改。
