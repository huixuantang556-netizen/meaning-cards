# 时间日历：同屏涂色工具栏

2026-10-21

修复在颜色、名称、精确时段和网格之间反复上下滚动的问题。本次只调整交互布局，不修改时间记录、加密格式或数据库。

## 现在怎样使用

- 打开日期后直接定位到涂色工作区。顶部显示日期切换、颜色、擦除、撤销和拖涂开关，下方紧接双栏15分钟网格。
- 工具和网格组成一个工作区。滚动一天内的时间时，工具仍在上方；手机颜色栏可以横向滑动，不需要回到页面顶部换色。
- 点击「名称 / 时段」打开小弹窗，可填写名称、应用到刚才选区或选择精确时间。填写后关闭弹窗，回到原来正在看的时段；不再把整张表往下挤。
- 原计划对照、时间定位、时区和旧日程参考放在网格下方。日统计、复盘与月历功能保留。
- 工作区按可见屏幕高度调整，并为睡前提示和手机底部导航保留空间。减少动画设置继续有效。

## 数据与测试

只更新 web/time-calendar.js、time-calendar.css、index.html、sw-secure.js。日历数据核心、账号配置、同步、加密、数据库和已有记录均不变。资源版本升为日历界面v3、缓存v9。

164项现有自动测试通过，JavaScript语法检查通过。隔离浏览器使用虚构账号验证：桌面滚到下午后，真实鼠标换色、填格时网格scrollTop与屏幕位置保持不变；手机横向换色不改变时间位置；精确补记与改名弹窗关闭后保留滚动位置；320×640和390×844首次打开时工具、列标题与时间格同屏，页面无横向溢出；两栏仍各96格；账号锁定后清空网格、弹窗文字与名称按钮内容。测试不等同于真实iOS/Android触摸设备验收。
