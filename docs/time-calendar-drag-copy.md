# 时间追踪：整段编辑、移动和框选复制

先保存未完成文字，再刷新页面。一天仍是双栏各96个独立15分钟格，连续活动始终保留网格线。

## 怎么操作

1. **涂色**：点击任意分类就会进入涂色模式，直接拖动即可连续填色，不需要再打开「拖涂」。空格单击可填色；已填格单击只聚焦，避免双击时先把事件覆盖。
2. **双击整段改名**：双击有颜色的活动，默认编辑当天同栏、同分类同事件名的连续区域。例如拖涂3小时后，双击任意一格即可给整段命名。仍可勾选「只修改双击的这一格」。键盘聚焦后按 Enter 也可打开编辑。
3. **移动**：点击「移动」，从活动内部按住拖到新位置，整段会一起移动，旧位置清空。若已有单栏框选范围，从该选区内部拖动可移动所选范围。
4. **框选复制**：点击「框选」，拖动选择时间范围；可选单栏，也可横跨计划与实际两栏。点击「复制」，再单击目标首格，点击「粘贴」。
5. **计划复制到实际**：框选计划栏，点击「复制」→「贴到另一栏」，即可复制到相同时间的实际栏；只允许已经发生的时间。不会自动把计划当成实际。
6. 复制和粘贴也支持在网格聚焦时使用 Ctrl/Cmd+C、Ctrl/Cmd+V。文本输入框的正常复制粘贴不受影响。复制内容只放在程序内存中，不自动写入系统剪贴板，不跨浏览器标签页；刷新或锁定后清空。
7. 手机可直接在格子上拖画、移动、框选；从左侧时间标签滚动表格。无需单独的拖涂开关。真实手机手势仍需最终体验验收。

## 覆盖、保存与隐私

目标范围已有记录时，先预览并确认替换。复制包含选区内的空白；确认后空白也会清除对应目标记录。取消不改变数据。移动与粘贴分别作为一次完整操作保存，点一次「撤销」即可恢复源和目标，不会只撤销其中一半。

只读原计划对照不允许复制或覆盖，需切回当前计划。旧版非整格记录不能直接复制或移动，避免把几分钟事实扩张成15分钟；原始记录仍保留，可逐格核对后编辑。超出当天/栏位边界、未来实际、源数据变化或账号/版本变化时拒绝写入。

沿用已有账号加密、离线缓存、自动同步和完整加密备份。没有执行SQL、改账号配置、导入私人资料或连接外部AI。

## 实际验证

178项自动测试通过，包括12格整段识别、整段改名、保留原计划快照、单/双栏复制、空白复制、移动、源目标重叠、跨日/夏令时边界、未来拒绝、陈旧源拒绝、192格替换与一次撤销、加密同步、新设备解锁及备份恢复。

隔离浏览器以虚构资料验证：直接拖画4格、双击整段修改、整段移动到空位并撤销、框选计划复制到实际、选目标粘贴、目标覆盖提示与取消/确认、单格编辑保留邻格、刷新重新解锁后保留记录、320宽度无横溢。键盘粘贴的自动验收受到测试浏览器虚拟剪贴板限制，按钮复制粘贴已实际验证；尚未做真实手机手指验收。
