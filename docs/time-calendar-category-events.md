# 时间追踪：自定义分类与单格事件

在时间追踪表颜色栏右侧点击「⚙ 分类」，选择「新增分类」，填写大类名称与颜色并保存。例如可添加「睡觉」。也可选已有分类修改名称或颜色。关闭设置后，新分类立即可用于涂色。最多30个分类；灰色「未知」保留原意与颜色。

大类用于分类统计，具体事件名独立保存。例如选择「生活照顾」填色后，再单击已填色格子，把具体事件改为「刷牙洗脸」，点击「保存此格」。也可以在编辑窗口改所属大类。

- 空白格：点击按当前颜色填写。
- 已填格：单击打开事件编辑，只修改当前15分钟格子。
- 连续拖动：继续批量涂色，即使起点已有颜色。
- 擦除模式：点已填格直接擦除，不打开编辑窗口。
- 取消编辑不保存；「撤销」可撤销最近的日历操作。
- 手机默认可滑动时间表；连续手指涂色仍须开启「拖涂」。

已存在的非整格记录若落在所选格内，编辑窗口会提示：保存会用完整15分钟替换这一格；取消可保留原来的分钟记录。

分类与事件沿用已有账号加密、离线保存、自动同步及加密备份。不更改数据库、密钥或用户已有记录。修改分类不会批量改写具体事件名。编辑时检查账号与日历版本，版本变化时拒绝覆盖并提示重新打开。锁定资料时清空编辑窗口的私人内容。
