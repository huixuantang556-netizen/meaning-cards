## 开发检查

安装 Node.js，在完整仓库根目录执行 `npm install`，然后 `npm test`。PGlite 0.5.10 用于本地 PostgreSQL 权限测试，不能代替真实 Supabase Auth 验收。

新增数据库脚本为 `supabase/002-encrypted-sync.sql`；只读检查为 `003-readonly-check.sql`；停用写入保留数据为 `002-disable-sync-preserve-data.sql`。正式数据库操作须先审核确认。

配置只使用项目公开 URL 与 Publishable key。禁止放入 secret/service_role、数据库密码、档案口令、GitHub PAT 或用户私人资料。

默认支持邮件登录链接，邮件提供验证码时也可输入验证码。默认测试邮件服务可能限制组织成员邮箱及发送频率；本轮未配置付费 SMTP。
